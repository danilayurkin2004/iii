# Блоки game.txt

`game.txt` (3165 строк, единый HTML-документ игры «Линия жизни») разбит на блоки в `blocks/`.
Номера строк в `_index.json` соответствуют оригинальному `game.txt`. Теги `<script>/<style>` из блоков сняты.

| Диапазон | Что это | Куда попали |
|---|---|---|
| 1–5 | `<head>`: meta/title | html/head.html |
| 6–34 | inline-скрипт темы | html/theme-script.js |
| 35–649 | `<style>` | css/css-01…css-08 (8 блоков) |
| 650–675 | разметка `<body>` | html/body.html |
| 676–3164 | главный `<script>` (IIFE) | js/js-01…js-48 (48 блоков) |
| 3165 | `</body></html>` | html/closing.html |

Разбиение полное и непересекающееся (проверено построчно). Оригинальный `game.txt` не изменялся.
